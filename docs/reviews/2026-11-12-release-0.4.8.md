## Follow-up repairs

- UDP replies now poll on EAGAIN and retain partial headers/payloads. An unanswered guest must
  not invent empty datagrams. The new response regression fails on the previous implementation.
- Docker listing retry state is scoped to a dockerd generation, cancelled on confirmed absence,
  and cannot update a successor. HTTP requests and event readers hold duplicate socket leases
  while cancellation closes the owning connection. Forced poll/close/dup2 reuse passes for
  both paths; replacing leases with raw fds fails both assertions.
- EOF closes exec connections and releases stdin credit waiters. Legacy guests accept at most
  4 KiB cumulative input from a new host; excess reports `guest_upgrade_required` and names
  `dmx stop` / `dmx guest fetch --force`. A new guest rejects legacy queue overflow without
  blocking its frame reader. Small stdin and SIGINT still work against the previous guest.
- A completed child's exit wins over unused stdin; explicit legacy incompatibility remains an
  error. `runInGuest` falls back to stopping the machine when shutdown acknowledgement fails,
  preserving the command result. Initial clock sync permits 15 s; periodic operations stay bounded.
- Clock sampling starts after opening its independent connection. The delayed-connect regression
  distinguishes the former false offset from the actual sample.
- Half-closed TCP connections expire after 30 minutes without data or valid peer ACK activity.
  Sending a probe alone does not renew the deadline.
- MCP timeout/cancellation closes the owning connection instead of issuing raw-fd shutdown.
  An isolated EOF/dup2/late-cancellation test preserves an unrelated socket's duplex traffic;
  restoring raw-fd shutdown fails it.
